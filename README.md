# 📱 NoMore — Flutter Habit Tracker & Productivity App

A Flutter habit tracker and daily productivity app featuring custom UI for habit building, to-do management, identity journaling, and motivational content.

> ℹ️ **Note**: This repository serves as a visual portfolio showcase for this project. Source code is kept private or unavailable.

## ✨ Key Features

* **Habit Tracking**: Set daily goals, track completion routines, and build habits.
* **To-Do Management**: Quick task creation and organized lists to manage daily chores.
* **Identity & Journaling**: Custom spaces to define core personal identities and write reflective journal entries.
* **Shorts & Motivation**: Integrated motivational quotes and curated bite-sized content categories.

## 🛠️ Tech Stack

* **Framework**: [Flutter](https://flutter.dev/)
* **Language**: [Dart](https://dart.dev/)
* **Platform Support**: Android & iOS
